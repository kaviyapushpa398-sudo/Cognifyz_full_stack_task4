# 🌐 Complex Form Validation & Dynamic DOM Manipulation

## 📌 Overview

This project focuses on building an interactive web application with **advanced form validation** and **dynamic DOM manipulation**. It enhances user experience by validating inputs in real-time and updating the UI dynamically.

---

## 🎯 Objective

To implement complex validation rules and create a responsive interface that reacts instantly to user interactions.

---

## 🏢 Project Source

This project was completed as part of a task provided by **Cognifyz**.

---

## 🛠️ Features Implemented

### ✅ 1. Advanced Form Validation

* Implemented complex validation rules such as:

  * Password strength (uppercase, lowercase, numbers, special characters)
  * Email format validation
* Displays real-time error and success messages

---

### ✅ 2. Dynamic DOM Manipulation

* Updates content dynamically based on user input
* Shows/hides elements without page reload
* Improves interactivity and responsiveness

---

### ✅ 3. Client-Side Routing

* Implemented navigation without reloading the page
* Provides a smoother user experience

---
